# Country boundaries

`countries.json` contains the Natural Earth **Admin 0 Countries, 1:50m**
boundary data, reduced to each feature's `ISO_A2_EH` country code and geometry.
It is used to colour Countries that contain the Account's saved Cities.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson
